# Бэклог на 4 недели: энергетики + студент

Период: ближайшие 4 рабочих недели  
Цель: закрыть предметную приёмку Этапа 1 и подготовить входные артефакты под Этап 2 (экология, рациональная структура, выходные формы).

## Роли

| Код | Кто | Зона |
|---|---|---|
| E1 | Энергетик 1 | Генерация, топливо, экология |
| E2 | Энергетик 2 | Нагрузки, спрос, балансы, прогноз, территории |
| S | Студент | Данные, сверки, инструкции, баг-листы |
| L | Руководитель (вы) | Приоритеты, приёмка артефактов, код |

## Единый шаблон артефактов

Папка сдачи: `Z:\НИО-10\АРМ ГС\Работы сотрудников\YYYY-WW\`

Обязательно по задаче:
- результат (xlsx / docx / pdf);
- README на 5–10 строк: что сделано, версия БД, ограничения;
- баги — в общий `BUGS.xlsx`.

### Шаблон строки BUGS.xlsx

| Поле | Пример |
|---|---|
| ID | BUG-2026-014 |
| Дата | 2026-09-22 |
| Автор | E1 / E2 / S |
| Модуль | Топливо / Нагрузки |
| Версия БД | СиПР 2026–2031 (рабочая) |
| Роль | редактор топлива |
| Шаги | 1… 2… 3… |
| Ожидалось | … |
| Факт | … |
| Скрин | путь |
| Критичность | блокер / высокий / средний / низкий |
| Статус | новый / подтверждён / исправлен / проверен |

### DoD (любая задача)

1. Файл в папке недели.  
2. Указаны версия БД и годы.  
3. Список блокеров для L.  
4. Баги в `BUGS.xlsx` (если есть).  
5. README заполнен.
