# Размещение статических файлов

## Проблема

При размещении статических файлов в `/opt/generation-app/app/app/static/` возникают проблемы с правами доступа:
- Каталог `/opt/generation-app` имеет права `drwxr-x---` (только владелец может войти)
- Пользователь `www-data` (от которого работает nginx) не может получить доступ к файлам
- Это приводит к ошибке `403 Forbidden` или `Permission denied`

## Решение

Статические файлы теперь размещаются в `/usr/share/generation-app/static/` согласно Debian-конвенциям:
- `/usr/share` предназначен для read-only данных приложений
- Права доступа: `755` для каталогов, `644` для файлов
- Доступен для чтения всем пользователям, включая `www-data`

## Настройка nginx

После установки пакета скопируйте пример конфигурации:

```bash
cat /usr/share/generation-app/nginx-static.conf.example
```

И добавьте соответствующий блок в конфигурацию вашего виртуального хоста nginx:

```nginx
location /static/ {
    alias /usr/share/generation-app/static/;
    
    # Кэширование статических файлов
    expires 30d;
    add_header Cache-Control "public, immutable";
    
    # Безопасность: отключаем выполнение скриптов в статике
    location ~ \.(php|pl|py|jsp|asp|sh|cgi)$ {
        deny all;
    }
    
    # Логирование (опционально)
    access_log off;
    log_not_found off;
}
```

**Важно:** Этот блок должен быть размещен **до** блока `location /`, который проксирует запросы к приложению.

## Автоматическая установка и обновление

### При установке нового пакета:
1. Статические файлы автоматически копируются в `/usr/share/generation-app/static/`
2. Устанавливаются правильные права доступа (755 для каталогов, 644 для файлов)
3. Владелец: `root:root` (для безопасности)

### При обновлении пакета:
1. **Файлы перезаписываются**: При обновлении deb-пакета файлы предыдущей версии **перезаписываются** новыми файлами (не удаляются и создаются заново)
2. **Миграция статики**: Если статика была в старом месте (`/opt/generation-app/app/app/static/`), она автоматически мигрирует в новое место (`/usr/share/generation-app/static/`)
3. **Очистка**: Старая статика из `/opt/` удаляется после успешной миграции
4. **Права доступа**: Автоматически устанавливаются правильные права на новую статику

### При удалении пакета (purge):
- Каталог `/usr/share/generation-app` полностью удаляется

## Преимущества

1. **Безопасность**: Статика отделена от исполняемого кода
2. **Производительность**: nginx обслуживает статику напрямую, без обращения к приложению
3. **Права доступа**: Нет проблем с доступом для `www-data`
4. **Соответствие стандартам**: Следует Debian-конвенциям для размещения данных приложений
