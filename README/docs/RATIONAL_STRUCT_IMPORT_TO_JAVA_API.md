# API исходных параметров рациональной структуры

На странице `/output_documents_transfer` активен набор
`rational_struct_calc / rational_struct_import_to_java.json`.
JSON и Excel используют один источник: сохраненные строки листа «Технологии»
страницы `/rational_structure/territory_technologies` выбранной версии БД.
Данные листа «МСК + МДП» в этот набор не входят.

## Запрос

```text
GET /api/datasets/37/rational_struct_import_to_java
GET /api/datasets/37/rational_struct_import_to_java?year=2026
```

По умолчанию «Год» равен году окончания периода Генеральной схемы
со страницы `/refdata/` выбранной версии БД. Используются те же
`get_current_year_info` и `get_general_scheme_end_year`, что и на странице
справочников. Например, для текущего года 2025 это 2042, даже если
период СиПР данной версии заканчивается в 2031 году.
Параметр `year` задает год расчета, не меняя параметры технологий:
в исходной таблице нет годовых срезов.
`start_year` и `end_year` ограничивают год выгрузки; они не создают
новые годовые срезы. Если год исключен фильтром, `rows` пуст.

## Соответствие полей

- «Тип технологии» – полное название строки технологии, без объединения
  разных типов оборудования в один общий тип ТЭС.
- «Тип топлива для технологии» – газ, уголь или прочее из сохраненного
  сопоставления; для АЭС с категорией «Прочее» – атомное.
  Если сопоставление не задано, передается пустая строка.
- Код энергозоны – номер из справочника энергозон, а не внутренний id.
- «Рmin, МВт» – произведение исходных `minimum_power` (о.е.) и `unit_power` (МВт).
- «Эмиссия СО2» – `co2_per_energy`, г/кВт·ч, не показатель кг/тут.
- Остальные числовые параметры – значения одноименных колонок без округления;
  пустые значения остаются `null`, нули остаются нулями.
- «Исходное приближенное значение» – `null`, так как поля нет в источнике.
- `external_code` – `null`, так как поле отсутствует в АРМ ГС.
  UUID при выгрузке не генерируется.

Оболочка соответствует общему API АРМ: `dataset`, `database_version`,
`version_number`, `version`, `comment`, `rows`. Поле `version` – числовой id
версии БД, не ISO-дата из примера mock. Набор включен в `/api/config` и
`/api/datasets`. Несуществующая версия возвращает 404; версия без
технологий возвращает `rows: []`, без подстановки mock-данных.
