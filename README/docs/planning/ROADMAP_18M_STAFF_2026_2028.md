# Дорожная карта предметной работы: 1,5 года

**Период:** сентябрь 2026 – март 2028 (≈18 месяцев)  
**Команда предметки:** E1, E2 (энергетики, полная ставка) + S (студент на практику / сменяемые практики)  
**Руководитель (L):** вы – код, приоритеты, приёмка артефактов  

Связанные документы:
- ближайшие 4 недели: `docs/planning/BACKLOG_4W_STAFF_2026.md`
- ТЗ 2026 (этапы 1–2), ТЗ 2027 (этапы 1–2)

---

## 1. Цель карты

Занять E1/E2 полной ставкой **без программирования** и обеспечить вас непрерывным потоком предметных входов:

| Вы (L) получаете | Они производят |
|---|---|
| Эталоны и допуски | Сверки АРМ ↔ Access/СиПР/ГИС ТЭК/ручной расчёт |
| Методики и поля | Спецификации модулей до кода |
| Чек-листы приёмки | Сценарии ролей, % прохождения, блокеры |
| Каталоги форм | Макеты и приоритеты выходных документов |
| Баг-поток | `BUGS.xlsx` + ретесты |
| Документация | Инструкции для пользователей и отчёты НИР |

**Правило:** код пишет только L. Если «нечем заняться» – расширяем сверки по ОЭС/годам/версиям, а не «помогите закодить».

## 2. Роли на весь горизонт

| Код | Зона ответственности (стабильно) |
|---|---|
| **E1** | Генерация, топливо, экология, рациональная структура, LCOE, ГИС ТЭК |
| **E2** | Нагрузки, графики нагрузки, спрос, балансы, электроёмкость, экономика (предметка), долгосрочный прогноз, характеристики территорий, каталог выходных форм, версии СиПР→ГС (предметные правила) |
| **S** | Наполненность БД, импорты, скрины, инструкции, баг-реестр, ретесты, архив эталонов |
| **L** | Приоритеты пятницы, приёмка файлов, код, блокеры |

### Студент (S) – как планировать на 1,5 года

Практика обычно 2–6 месяцев. Карта рассчитана на **конвейер практикантов**:
- один и тот же набор учебных треков (см. §7);
- стартовый пакет: доступы, шаблон BUGS, папка недели, 3 инструкции;
- E1/E2 – наставники по содержанию, L – по приёмке.

Если студента нет – его очередь переходит E1/E2 как «фоновая» (инструкции + наполненность 0,5 дня/нед.).

## 10. Как пользоваться этой картой

1. **Раз в квартал** (1–2 часа): L + E1 + E2 выбирают 5–7 пакетов из соответствующего квартала → детальный бэклог на 4 недели (по образцу `BACKLOG_4W_STAFF_2026.md`).  
2. **Каждый понедельник:** у каждого не больше 2 активных задач с датой сдачи в пятницу.
