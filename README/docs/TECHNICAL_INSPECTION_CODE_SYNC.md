# Связки агрегатов с кодами Техинспекции

Код Техинспекции хранится отдельно от годовых характеристик оборудования.
При ручном указании ID агрегата в таблице технических характеристик или кода
в карточке агрегата связь сохраняется во всех версиях, в которых найден
однозначный агрегат с тем же `external_code`. Для составляющей ПГУ дополнительно
проверяется `id_ti`, а при его отсутствии – нормализованный номер составляющей.

Сохранение связи также обновляет ID и статус сопоставления уже загруженных строк
с этим кодом за другие годы и в других версиях. Мощности, наработки и остальные
характеристики не копируются и не изменяются. Если в другой версии код уже связан
с другим агрегатом, такая связь автоматически не заменяется.

## Перенос существующих связок

Из корня проекта, в окружении приложения:

```powershell
.venv/Scripts/python.exe scripts/backfill_technical_inspection_codes.py
```

Без `--apply` скрипт проверяет перенос в транзакции и откатывает изменения.
Отчет JSON содержит:

- `created` – количество добавляемых записей связи;
- `linked_rows` – количество строк характеристик с обновляемым сопоставлением;
- `conflicts` – коды с противоречащими друг другу связями;
- `skipped` – агрегаты без `external_code`, неоднозначные агрегаты и составляющие ПГУ.

После проверки отчета применить перенос:

```powershell
.venv/Scripts/python.exe scripts/backfill_technical_inspection_codes.py --apply
```

Источники – существующие отдельные связи и строки технических характеристик со
статусом `matched`. Скрипт не создает строки характеристик в других версиях,
не переносит годовые значения и не выбирает агрегат при неоднозначном совпадении.
Повторный запуск не создает дубликаты. При ошибке откатывается вся транзакция.

## Импорт Excel

- Загружаются все годы, присутствующие в файле. Год над таблицей влияет только
  на отображение и адрес возврата после импорта.
- Характеристики добавляются или обновляются только в текущей версии БД по
  ключу «вид оборудования + код оборудования + год».
- Сначала проверяется сохраненная связь по коду Техинспекции, включая связь
  из другой версии по `external_code`.
- Если код неизвестен, используется существующий алгоритм сопоставления с
  параметрами агрегата за год конкретной строки Excel.
- Неоднозначная связь по коду не заменяется результатом параметрического поиска.
- При точном совпадении код сохраняется отдельно, в том числе для соответствующих
  агрегатов других версий. Годовые значения туда не копируются.
- Ошибка в любом году файла отменяет весь импорт.

При редактировании кода в карточке исходный код в ранее загруженных строках Excel
не переписывается: старая связь снимается, новая сохраняется отдельно. Если строки
с новым кодом уже есть, их сопоставление обновляется.
