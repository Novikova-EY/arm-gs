# Коэффициент K в удельных показателях

## Текущее состояние (после миграции i1j2k3l4m5n6)

**K хранится только в `EquipmentGroupSpecificFuelConsumption.k` (consumption.k)** с привязкой к году.

Колонка `EquipmentGroup.k` удалена из БД.

## Использование K

- **Формула btp_calc:** `btp_calc = EURT - K * (1 - EWTP / E) * 100` — единственная формула, использующая K
- **Пересчет:** использует `consumption.k` для (equipment_group_id, year_number)
- **Редактирование:** таблица «Удельные показатели» на странице карточки группы оборудования, столбец «К» по годам
- **Импорт:** импорт коэффициента K из Excel записывает в `consumption.k`
