# API замыкающих цен

`GET /api/datasets/<database_version>/import_gs_to_ee_zam_cena`

Кнопка `import_gs_to_ee_zam_cena.json` на `/output_documents_transfer` открывает набор выбранной версии БД. Для администратора доступна стандартная выгрузка этого же набора в Excel.

Источник: сохраненная книга `/rational_structure/marginal_price` выбранной версии БД, все территории и годы книги. Числа округляются по mock независимо от экранных настроек. Поддерживаются общие фильтры API `year`, `start_year`, `end_year`.

Пример:

```text
/api/datasets/37/import_gs_to_ee_zam_cena?start_year=2025&end_year=2042
```

## Оболочка

Как и у остальных наборов обмена, `database_version` и `version` содержат числовой ID версии БД, `version_number` – ее название. Дата из mock-примера не используется как версия реальных данных. `dataset` равен `import_gs_to_ee_zam_cena`, `comment` – пустая строка, `rows` – список строк.

## Поля строки

| Поле | Источник |
| --- | --- |
| Группа ОЭС (ЗЦ) | Территория книги: Европ.часть, Юг, Урал, Сибирь, Восток |
| ОЭС (ЗЦ) | ОЭС по прямой связи станции с РЭС |
| Год | Столбец A |
| План/Факт (ЗЦ) | Название признака из `/refdata/years` для года, равного полю «Год» этой строки, в выбранной версии БД; без переименования |
| Номер ступени | Столбец B |
| Название замыкающей станции ступени | Станция из столбца «Название станции» страницы, связанная с сопоставленной группой оборудования |
| Прогнозная цена электроэнергии замыкающей станции ГС, руб. без НДС/кВт*ч | Столбец C: Цена 1 кВт·ч, руб. |

## Округление JSON и Excel

- Цена электроэнергии – 2 знака после запятой (`2.01`).
- Продолжительность, мощность и выработка периода – 1 знак после запятой (`30.2`, `500.0`, `300.3`).
- Годовая выработка – целое число (`579553`).
- Используется `ROUND_HALF_UP`: `2.005` → `2.01`, `30.25` → `30.3`.
- Годовая выработка сначала суммируется из исходных значений P, затем округляется до целого. Исходная книга и расчеты страницы не изменяются.
- Значения остаются числами, отсутствующие значения остаются `null`.

## Неполные данные

- Сопоставление групп и станций выполняется заново при запросе, по тем же правилам, что на странице.
- Если у группы несколько станций, для каждой создается строка с собственными названием, кодом и ОЭС. Показатели ступени и годовая энергия остаются общими; строки нельзя повторно суммировать для получения годовой энергии.
- Если группа не сопоставлена или у нее нет связанных станций, строка сохраняется с показателями, но название станции, код и ОЭС равны `null`. Название группы оборудования не подставляется вместо станции.
- Если прямой связи станции с РЭС/ОЭС нет, ОЭС равна `null`. Ссылки на справочники другой версии БД не используются.
- Признак определяется отдельно для каждой строки по ее полю «Год», а не один раз для всей выгрузки. Изменение признака в справочнике учитывается при следующем запросе API.
- Если год или его признак отсутствует в справочнике версии, План/Факт равен `null`; признак не выводится из календарной даты и не заимствуется у другого года или версии БД.
- Ошибка Excel или отсутствующее числовое значение передаются как `null`, нулевые значения сохраняются. Если энергия хотя бы одного периода территории и года некорректна, годовая энергия равна `null` во всех строках этого года и территории, как на странице.
- Без загруженной книги возвращается пустой `rows`. Несуществующая версия БД дает стандартный ответ API `404 unknown_database_version`.
