# Сброс личных настроек

На странице `/users` администратор может нажать «Сбросить настройки» в строке пользователя и подтвердить действие. Это отдельный POST с CSRF-защитой: изменения логинов, ролей и удаления из основной формы не отправляются.

При следующем запросе пользователя удаляются сохраненные серверные фильтры списка станций и проверки внешних кодов. При открытии HTML-страницы удаляются известные настройки отображения из localStorage и sessionStorage: годы, округление, видимость строк и столбцов, сворачивание групп, фильтры территорий, восстановление прокрутки. В каждой вкладке и каждом браузере сброс применяется один раз для данного маркера.

Авторизация, CSRF, выбранная версия БД, данные расчетов, отчеты импорта, идентификаторы фоновых заданий и общий кеш не очищаются. Явно заданные параметры URL продолжают действовать. Уже открытая страница меняется только после нового открытия или обновления, без прерывания редактирования.

Маркеры сохраняются атомарно в `<Flask instance_path>/user_settings_resets/<user_id>.txt`. Каталог должен быть доступен приложению для записи и сохраняться при перезапуске. Все процессы приложения должны использовать один каталог; при размещении на нескольких серверах нужен общий том для instance_path. Изменений схемы БД не требуется. Общая очистка кеша не отменяет отложенный сброс.

Существующие настройки браузера исторически не разделены по учетным записям: если несколько людей используют один профиль браузера на одном адресе, эти настройки у них общие. Для независимых настроек нужны отдельные профили браузера. Команда сброса доставляется только выбранной учетной записи.
