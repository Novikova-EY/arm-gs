- ✅ Настраиваемое расписание через переменные окружения
- ✅ Автоматическая очистка старых бэкапов
- ✅ Настраиваемое количество хранимых бэкапов
- ✅ Полное логирование всех операций
- ✅ Использование pg_dump для сжатых бэкапов
- ✅ Поддержка Windows и Linux

**Конфигурация (.env):**
```bash
# Включить автоматические бэкапы
ENABLE_SCHEDULED_BACKUPS=True

# Директория для бэкапов
AUTO_BACKUP_DIR=backups/auto

# Количество хранимых бэкапов
KEEP_AUTO_BACKUPS=7

# Расписание (каждый день в 2:00)
BACKUP_SCHEDULE_HOUR=2
BACKUP_SCHEDULE_MINUTE=0
```

**Расписание:**
- По умолчанию: каждый день в 2:00
- Настраиваемо через переменные окружения
- Поддержка cron-выражений для сложных расписаний

**Файлы:**
- `app/common/services/scheduled_backup_service.py` - сервис
- `config.py` - настройки
- `requirements.txt` - добавлен APScheduler==3.10.4
- Документация: `README/VERSIONING/AUTOMATIC_BACKUPS.md`
