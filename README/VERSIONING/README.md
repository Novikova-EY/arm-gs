## 🚀 Быстрый старт

### Для новых пользователей

**5 шагов к началу работы:**

1. **📖 Прочитайте основы** (15 минут)
   - Раздел "Концепция версионирования" в [USER_GUIDE.md](USER_GUIDE.md)

2. **➕ Создайте первую версию**
   ```
   Меню → Управление версиями БД → ➕ Добавить версию
   Номер: 1
   Название: Версия 1.0 - Базовая
   ```

3. **✅ Активируйте версию**
   ```
   Управление версиями БД → ✅ Установить активной
   ```

4. **💾 Создайте снимок**
   ```
   Управление версиями БД → 💾 Создать снимок
   ```

5. **⚙️ Настройте автобэкапы** (для админов)
   - См. [AUTOMATIC_BACKUPS.md](AUTOMATIC_BACKUPS.md)

**Готово!** Теперь можете работать с версиями.

│                   Веб-интерфейс                         │

## 🔐 Безопасность

### Меры безопасности

✅ **Автоматический бэкап перед восстановлением**
- Перед загрузкой снимка создается автоматический бэкап текущего состояния

✅ **Нельзя удалить активную версию**
- Защита от случайного удаления используемой версии

✅ **Логирование всех операций**
- Все действия с версиями записываются в лог

✅ **Транзакционность**
- Все операции выполняются в транзакциях

✅ **Проверка прав доступа**
- Только авторизованные пользователи могут управлять версиями

### Рекомендации

⚠️ **Файлы бэкапов**
- Содержат все данные БД - храните их в безопасном месте
- Не размещайте в публично доступных директориях
- Рассмотрите шифрование для production

⚠️ **Доступ к pg_dump/pg_restore**
- Требуется доступ к утилитам PostgreSQL
- Убедитесь, что пароль БД защищен

⚠️ **Дисковое пространство**
- Бэкапы занимают 50-200 МБ каждый
- Мониторьте свободное место на диске

## 📞 Поддержка

### Получить помощь

1. **Прочитайте FAQ** в [USER_GUIDE.md](USER_GUIDE.md#faq-и-решение-проблем)
2. **Проверьте логи** в `logs/app.log`
3. **См. шпаргалку** в [QUICK_REFERENCE.md](QUICK_REFERENCE.md)
4. **Обратитесь к администратору** системы

### Полезные команды для диагностики

```bash
# Просмотр логов
tail -f logs/app.log | grep -i version

# Проверка бэкапов
ls -lh backups/*/

# Проверка размера БД
psql -U postgres -d arm_gs -c "SELECT pg_size_pretty(pg_database_size('arm_gs'));"

# Проверка версий
psql -U postgres -d arm_gs -c "SELECT * FROM refdata.database_versions;"
```
