# Разбор кнопок «Коэфф / Распред / Топливо»

Access: форма **«Расчет»** в **«Топливо на ГС.mdb»** · АРМ: страница `/fuel/calculation`

| Access | Обработчик |
|--------|------------|
| Коэфф | `Кнопка5_Click` |
| Распред | `Кнопка27_Click` |
| Топливо | `Кнопка49_Click` |

**Порядок обязателен:** сначала Коэфф (агрегаты + EWTP и К=), затем Распред (раздача Ераспред → E по станциям), затем Топливо (EOTP/EURT/B и formtxt). В веб-«Распред» Коэфф вызывается автоматически перед итерациями.

**High-impact:** H=NULL→синтез E/N·1000 в Распред (иначе E=EWTP·1.04), obor 24|89→knps, итерации 14/16, Skip если нет удельника year≤расч. / нет формулы, formtxt `name=-1` абсолют, **gaz = gaz_prir+gazpp (GROUPS, как СиПР MDB)**, proch Access. Остаётся: MsgBox NR→HFIX, упрощённый filter, wname/uname как ORM.

**Параметры распределения участвуют во всех трёх этапах** — это не кнопка, а выбранный сценарий расчёта. Без строки `DistributionParameter` Коэфф/Распред/Топливо не запускаются. Из параметра читаются: `filter` (отбор станций), `year` / `base_year`, `e` (Ераспред), `doptim`, `hnps`/`hngt`/`hnpg` (ЧЧИУМ → kn*), стартовые `k`/`kn`; этап Распред пишет обратно `k`/`kn`/`kn*`/`lim`. Сводка агрегатов Коэфф — в `DistributionCoefficientSummary` (не все поля на самой карточке параметра).

**wname / uname / toplname / dopname:** не зашиты в коде. На форме «Расчет» читаются из строки `параметры-распределения`; VBA: `Set w = db.OpenRecordset(wname, …)`. Для варианта «Схема» обычно: `Станции(Схема)`, `Удельные(Схема)`, `Формулы_топлива(Схема)`, `Доп_угли(Схема)`. Иначе — как задано в параметре / «Список-вариантов» (например `Станции(Анализ_и_прогноз)`). В АРМ эти поля на `DistributionParameter` только для трассируемости; данные станций — `EquipmentGroupFuelParam` (`gs_fue_equipment_group_fuel_params`).

## Укрупнённый анализ: что делает каждая кнопка

### Коэфф — `Кнопка5_Click`

| | |
|--|--|
| **Зачем** | Подготовить коэффициенты и сводку для раздачи энергии: пересчитать Этц (EWTP) и получить К= (`ph`), Hср (`ch`), Кнов (`kn*`). |
| **Что делает** | 1) Обходит станции фильтра (база + расчётный год). 2) Пишет `EWTP = QOTR·y/1000`: y из последнего удельника с `year ≤` расчётного; если такой строки нет → Skip. 3) Копит ΣNUST/E/EWTP/Q и «новые» мощности (ПС/ГТ/ПГ). 4) Считает `ch`, `knps/kngt/knpg`, `hd`, `ph`, `pq`, `potr` → сводка Коэфф. |
| **Результат** | `DistributionCoefficientSummary` + `ewtp` на станциях. Главный выход для Распред: `ph`, `ch`, `kn*`. |
| **АРМ** | `FuelCoefficientCalculationService` · `POST …/run_coeff` |

### Распред — `Кнопка27_Click`

| | |
|--|--|
| **Зачем** | Раздать целевое Ераспред по станциям: подобрать общий `K` (или `kn`) так, чтобы сумма E сошлась с заданием. |
| **Что делает** | 1) (АРМ) Сначала авто-Коэфф. 2) По станции: часы H из базы / «новая» / HFIX; `H = hb·koptim·K·Nivh·kobl`. 3) `E = max(N·H/1000, EWTP·1.04)`, затем `H = E/N·1000`. 4) Бисекция K до \|Е−ΣE\|&lt;0.3 (до 16 проходов); при ограничениях — внешний цикл kobl/emin/emax (14). |
| **Результат** | На станциях: `e`, `h`, `ewtp`. На параметре: `k`/`kn`/`kn*`, `lim`. |
| **АРМ** | `DistributionStageService` · `POST …/run_distribution` |

### Топливо — `Кнопка49_Click`

| | |
|--|--|
| **Зачем** | По уже распределённой E посчитать отпуск топлива (EOTP/B) и разложить B по видам топлива по `formtxt`. |
| **Что делает** | 1) Снова EWTP (тот же выбор удельника: последний `year ≤` расчётного; иначе Skip); без формулы — Skip (строка не меняется). 2) EOTP/EUST/EURT/TUST/B (ветки VED 1/4: snbas/ksn, bbas/kh). 3) Разбор formtxt (% / абсолют `name=-1` / остаток). 4) Укрупнение: `gaz = gaz_prir+gazpp` (GROUPS), бассейны по used_names, proch Access-корзина. |
| **Результат** | На станции: eotp, eust, eurt, tust, b, gaz/mazut/…; в доп. углях — листья formtxt. |
| **АРМ** | `EquipmentGroupFuelCalculationService` · `POST …/run_fuel` |

## 2a. Ограничения — поля и учёт в расчёте

Access: ограничения действуют только пока открыта форма **«Анализ_по_областям»** (`brestr=True`). В АРМ — чекбокс **«Учитывать ограничения в расчетах»** рядом с кнопкой «Ограничения» на `/fuel/calculation`.

|-------------------|------|------------|-----------|
| year | Год расчёта | ключ строки | фильтр oes+year |
| oes | Код ОЭС | ключ | из filter_text параметра |
| name | Наименование субъекта | справочно | нет |
| obl | Код субъекта РФ | ключ | поиск kobl для группы |

## 2b. Фиксированные_часы — HFIX (признак фиксации ЧЧИУМ)

| фильтр станций | фильтры edit_data / параметр распределения | как filter1 на «Расчет» |

## Ключевые формулы (кратко)

```text
Коэфф:  EWTP = QOTR·y/1000
         ch = Ераспред / ΣNUST · 1000
         ph = hd / Hбаз

Распред: H = Hбаз · koptim(bk) · K · Nivh · kobl
         E = max(N·H/1000, EWTP·1.04)   [или EWTP для obor 8..10]
         подобрать K: |Ераспред − ΣE| < 0.3

Топливо: EOTP = (E−EWTP)·(1−snk/100) + EWTP·sntp
         EUST = (Eкот·bk + Eтп·btp)/1000
         B = EUST + Q·TURT/1000
         formtxt → доли топлива от B
```
