# Разбор кнопок «Коэфф / Распред / Топливо»

Эталон: **живая форма «Расчет»** в СиПР (`СиПР ЭЭС_2031_4 этап.mdb`, август 2026), не устный «шаг назад, пока не найдём» и не Bookmark соседней станции. АРМ: страница `/fuel/calculation`.

Полный эталон расчёта (Коэфф → Распред → Топливо по каждой ОЭС, 2026–2031, без формы ограничений): копия `_otet_analysis/sipr_etalon/sipr_ees_2031_etalon.mdb`. Собрать: `python scripts/fuel_access_etalon.py all`. Прогон АРМ тем же порядком: `python scripts/run_arm_fuel_three_buttons.py`. Сверка: `python scripts/compare_fuel_vs_access_etalon.py`.

| Access  | Обработчик       |
| ------- | ---------------- |
| Коэфф   | `Кнопка5_Click`  |
| Распред | `Кнопка27_Click` |
| Топливо | `Кнопка49_Click` |

**Порядок как в Access:** сначала Коэфф (агрегаты + EWTP и К=), затем при необходимости правка EWTP, затем Распред (раздача Ераспред → E по станциям), затем Топливо (EOTP/EURT/B и formtxt). Распред **не** вызывает Коэфф.

**Сверка (август 2026):** ядро трёх кнопок совпадает с живой Кнопка5 / Кнопка27 / Кнопка49 СиПР.

| Тема                    | Access сейчас                                                                                   | АРМ сейчас                                                                        | Сверка                                               |

### Спорные ситуации — как решили

| Вопрос                                                         | Решение                                                                                                                                                                    | Что это значит                                         |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| Нет удельных на расчётный год — Skip, прошлый год или соседка? | **Skip**, если у этой станции нет строки в `[базовый, расчётный]`. 2024 при расчёте 2026 — да (это окно Seek). 2021 — нет. Соседку не берём. Пустая строка в окне — Match. | Одна функция на три кнопки.                            |
| Пустой HFIX — прирост мощности учитывать?                      | **Нет.** Null ≠ 0. Прирост (`старая N на H`, `ΔN на ch`) только при `HFIX=0`. `HFIX=1` часы не трогает.                                                                    | Пустой признак не включает развилку прироста.          |
| Пустой `h` на базе — новая или восстановить из E/N?            | **Новая:** `H = ch · Кнов`. Действующую **масштабируют от базы:** `H = hb · koptim · K · Nivh · kobl`.                                                                     | Не подставляем `E/N·1000` вместо пустого `h`.          |
| Порог часов 6500 или 6000 — одна проверка?                     | **Две разные.** Clamp Распред: зона `hb∈(6500, 7000)` и `hd<6000` → не больше +5%. Nivh: `hb>6000` → `ke=1`.                                                               | `hd<6000` в clamp — про часы действующих, не про `hb`. |
| Нет формулы на базовый год — взять отчёт 2021 или Skip?        | **Skip**, как Access Seek. Отчётную формулу переносят **записью на базовый год**. Смену баланса на перспективе ставят **с года изменения**, не копируя каждый год. | Без строки в `[byear, cyear]` топливо по станции не считается. |

Парсер фильтра в АРМ не умеет OR/LIKE/NOT/IN — на текущей БД таких фильтров нет. Поле `v` у удельных в АРМ нет (одна строка на группу+год); пока в Access только `v=0`, расхождения нет.

| Access                                              | АРМ ГС                                   | Точка входа                                                       |
| --------------------------------------------------- | ---------------------------------------- | ----------------------------------------------------------------- |

| Кнопка49_Click (Топливо)                            | `EquipmentGroupFuelCalculationService`   | `POST …/run_fuel`                                                 |
| Ограничения + Анализ*по*областям                    | `FuelRestriction` + `apply_restrictions` | `/fuel/restrictions?edit=1`                                       |
| Фиксированные_часы (H / HFIX)                       | `h` + `hfix` на FuelParam                | группа «Часы» на edit_data: «ЧЧИУМ, ч» / «Признак фиксации ЧЧИУМ» |
| Станции(Схема)                                      | `EquipmentGroupFuelParam`                | e, q, qotr, ewtp, h, hfix, …                                      |
| Удельные(Схема)                                     | `EquipmentGroupSpecificFuelConsumption`  | y, snk, sntp, bk, btp, snbas, ksn, bbas, kh                       |
| Формулы_топлива(Схема)                              | `EquipmentGroupFuelFormula.formtxt`      | разбор долей топлива                                              |

**Параметры распределения участвуют во всех трёх этапах** — это не кнопка, а выбранный сценарий расчёта. Без строки `DistributionParameter` Коэфф/Распред/Топливо не запускаются. Из параметра читаются: `filter` (отбор станций), `year` / `base_year`, `e` (Ераспред), `doptim`, `hnps`/`hngt`/`hnpg` (ЧЧИУМ → kn*), стартовые `k`/`kn`; этап Распред пишет обратно `k`/`kn`/`kn*`/`lim`. Сводка агрегатов Коэфф — в `DistributionCoefficientSummary` (не все поля на самой карточке параметра).

**wname / uname / toplname / dopname:** не зашиты в коде. На форме «Расчет» читаются из строки `параметры-распределения`; VBA: `Set w = db.OpenRecordset(wname, …)`. Для варианта «Схема» обычно: `Станции(Схема)`, `Удельные(Схема)`, `Формулы_топлива(Схема)`, `Доп_угли(Схема)`. Иначе — как задано в параметре / «Список-вариантов» (например `Станции(Анализ_и_прогноз)`). В АРМ эти поля на `DistributionParameter` только для трассируемости; данные станций — `EquipmentGroupFuelParam` (`gs_fue_equipment_group_fuel_params`).

## Укрупнённый анализ: что делает каждая кнопка

### Коэфф — `Кнопка5_Click`

|                |                                                                                                                                                                                                                                                                                                |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Зачем**      | Подготовить коэффициенты и сводку для раздачи энергии: пересчитать Этц (EWTP) и получить К= (`ph`), Hср (`ch`), Кнов (`kn*`).                                                                                                                                                                  |
| **Что делает** | 1) Обходит станции фильтра (база + расчётный год). 2) Пишет `EWTP = QOTR·y/1000`: y из Seek `[byear, cyear]` этой станции; нет строк → Skip. 3) Копит ΣNUST/E/EWTP/Q и «новые» (ГТ в суммах — только obor 20\|90). 4) Считает `ch`, `knps/kngt/knpg`, `hd`, `ph`, `pq`, `potr` → сводка Коэфф. |
| **Результат**  | `DistributionCoefficientSummary` + `ewtp` на станциях. Главный выход для Распред: `ph`, `ch`, `kn*`.                                                                                                                                                                                           |
| **АРМ**        | `FuelCoefficientCalculationService` · `POST …/run_coeff`                                                                                                                                                                                                                                       |

### Распред — `Кнопка27_Click`

|                |                                                                                                                                                                                                                                                                                                                                              |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Зачем**      | Раздать целевое Ераспред по станциям: подобрать общий `K` (или `kn`) так, чтобы сумма E сошлась с заданием.                                                                                                                                                                                                                                  |
| **Что делает** | 1) Берёт уже сохранённую сводку Коэфф (`ph`/`ch`/`kn*`) и EWTP на станциях (не пересчитывает). 2) По станции: часы H из базы / «новая» / HFIX; `H = hb·koptim·K·Nivh·kobl`. 3) `E = max(N·H/1000, EWTP·1.04)`, затем `H = E/N·1000`. 4) Бисекция K до \|Е−ΣE\|&lt;0.3 (до 16 проходов); при ограничениях — внешний цикл kobl/emin/emax (14). |
| **Результат**  | На станциях: `e`, `h` (EWTP не трогает). На параметре: `k`/`kn`/`kn*`, `lim`.                                                                                                                                                                                                                                                                |
| **АРМ**        | `DistributionStageService` · `POST …/run_distribution`                                                                                                                                                                                                                                                                                       |

### Топливо — `Кнопка49_Click`

|                |                                                                                                                                                                                                                                                                                                             |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Зачем**      | По уже распределённой E посчитать отпуск топлива (EOTP/B) и разложить B по видам топлива по `formtxt`.                                                                                                                                                                                                      |
| **Что делает** | 1) Снова EWTP (тот же Seek `[byear, cyear]`; иначе Skip); без формулы — Skip (строка не меняется). 2) EOTP/EUST/EURT/TUST/B (ветки VED 1/4: snbas/ksn, bbas/kh). 3) Разбор formtxt (% / абсолют `name=-1` / остаток). 4) Укрупнение по иерархии: `gaz = gaz_prir + gazpp`, бассейны по used_names, proch Access-корзина. |
| **Результат**  | На станции: eotp, eust, eurt, tust, b, gaz/mazut/…; в доп. углях — листья formtxt.                                                                                                                                                                                                                          |
| **АРМ**        | `EquipmentGroupFuelCalculationService` · `POST …/run_fuel`                                                                                                                                                                                                                                                  |

## Ключевые формулы (кратко)

```text
Коэфф:  EWTP = QOTR·y/1000
         ch = Ераспред / ΣNUST · 1000
         ph = hd / Hбаз

Распред: H = Hбаз · koptim(bk) · K · Nivh · kobl
         E = max(N·H/1000, EWTP·1.04)   [или EWTP для obor 8..10]
         подобрать K: |Ераспред − ΣE| < 0.3

Топливо: EOTP = (E−EWTP)·(1−snk/100) + EWTP·sntp
         EUST = (Eкот·bk + Eтп·btp)/1000
         B = EUST + Q·TURT/1000
         formtxt → доли топлива от B
```
