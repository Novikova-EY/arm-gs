Что считает пакет и что записывается в БД

Для каждой отобранной группы вызывается EquipmentGroupFuelCalculationService.calculate_group_year (логика из Access-модуля). Запись в таблицах gs_fue_equipment_group_fuel_param и gs_fue_equipment_group_extra_fuel_param по паре группа + год расчета. На вход берутся уже сохраненные удельный расход (строка с наибольшим year_number среди записей группы, у которых year_number ≤ году расчёта; это не означает обязательный выбор «предыдущего календарного года»: если, например, для 2032 в таблице нет строки за 2031, подставится последняя имеющаяся по году — за 2030, 2025 и т.д.), формула топлива formtxt (вариант из формы; версия БД — по умолчанию) и поля энергобаланса из строки параметров топлива: e (Выработка ЭЭ, млн кВтч), q (Отпуск ТЭ, тыс.Гкал), qotr (Тепловое потребление (отборов турбин), тыс.Гкал), turt (УРУТ на отпуск ТЭ, кг у.т./⁠Гкал) — подписи как в шапках таблицы «Рассчитанные параметры» / основные топливные параметры на этой странице.

Кратко: строка удельных показателей (EquipmentGroupSpecificFuelConsumption) выбирается как последняя запись с year_number ≤ году расчёта; строка формулы (EquipmentGroupFuelFormula) — как последняя с year_number ≤ году расчёта для выбранного variant_number (с учётом версии БД). Сам расчёт выполняется через EquipmentGroupFuelCalculationService.calculate_group_year. По умолчанию в этом интерфейсе включён commit_each (коммит после каждой группы); ошибка по одной группе не останавливает остальные, пока не включён stop_on_error.

Энергетический блок

Берётся строка удельного расхода (EquipmentGroupSpecificFuelConsumption) с максимальным year_number среди строк этой группы, где year_number ≤ году расчёта (в коде — ORDER BY year_number DESC LIMIT 1; это не «всегда год расчёта минус один», а фактически последняя заведённая строка, не превышающая год расчёта). Поля из неё: y (удельная выработка ЭЭ на тепловом потреблении, кВтч/⁠Гкал), snk (СН на выработку ЭЭ, %), sntp (коэффициент отпуска ЭЭ в теплофикационном режиме), bk (УРУТ на отпуск ЭЭ в конденсационном режиме, г у.т./кВтч), btp (УРУТ на отпуск ЭЭ в теплофикационном режиме, г у.т./кВтч) — те же подписи, что в шапке таблицы «Удельные показатели групп оборудования». И уже сохранённые поля энергобаланса из параметров топлива для этого года: qotr (Тепловое потребление (отборов турбин), тыс.Гкал), e (Выработка ЭЭ, млн кВтч), q (Отпуск ТЭ, тыс.Гкал), turt (УРУТ на отпуск ТЭ, кг у.т./⁠Гкал).

Далее по логике Access-модуля (_calculate_energy_part):

  • ewtp (Теплофикационная выработка ЭЭ, тыс.кВтч) = qotr (Тепловое потребление (отборов турбин), тыс.Гкал)·y / 1000;
  • eotp (Отпуск ЭЭ, млн кВтч) = ekotp + etpotp, где ekotp = (e (Выработка ЭЭ, млн кВтч) − ewtp (Теплофикационная выработка ЭЭ, тыс.кВтч))·(1 − snk/100), etpotp = ewtp·sntp;
  • eust (Расх топ эл.эн.) = (ekotp·bk + etpotp·btp) / 1000 (bk, btp — из строки удельного расхода, см. подписи выше);
  • eurt (УРУТ на отпуск ЭЭ, г у.т./кВтч) = (eust / eotp)·1000 (при eotp ≠ 0, иначе 0);
  • tust (Расход усл. топлива на ТЭ, тыс. т у.т.) = q (Отпуск ТЭ, тыс.Гкал)·turt (УРУТ на отпуск ТЭ, кг у.т./⁠Гкал) / 1000;
  • b (Расход топлива, всего) = eust + tust — база для разложения по formtxt на следующем этапе.

Рассчитанные показатели в таблице на этой странице совпадают с колонками Теплофикационная выработка ЭЭ, тыс.кВтч, Отпуск ЭЭ, млн кВтч, УРУТ на отпуск ЭЭ, г у.т./кВтч, Расх топ эл.эн., Расход усл. топлива на ТЭ, тыс. т у.т., Расход топлива, всего.

EquipmentGroupFuelParam (перезапись рассчитанными значениями) — в строку с тем же year_number, что и год расчёта в форме пакета (колонка year_number в gs_fue_equipment_group_fuel_param: одна запись на пару «группа оборудования + этот год»).

  • ewtp — Теплофикационная выработка ЭЭ, тыс.кВтч
  • eotp — Отпуск ЭЭ, млн кВтч
  • eust — Расх топ эл.эн.
  • eurt — УРУТ на отпуск ЭЭ, г у.т./кВтч
  • tust — Расход усл. топлива на ТЭ, тыс. т у.т.
  • b — Расход топлива, всего
Распределение по видам топлива

Перед разбором формулы вызываются _reset_main_fuel_fields и _reset_extra_fuel_fields: в ноль сбрасываются рассчитанные ранее колонки топлива на EquipmentGroupFuelParam (объединение наборов TOPLS и UGLI — газ/мазут/прочее и углеводородные агрегаты) и детальные поля «доп. углей» на EquipmentGroupExtraFuelParam (набор UGLI1).

Строка formtxt берётся из подходящей записи EquipmentGroupFuelFormula (год ≤ году расчёта, нужный variant_number, учёт версии БД при выборе строки формулы). Разбор — _parse_formtxt:

  • фрагменты через «;»;
  • вид имя=доля — доля в % от b (база по умолчанию — полный b; префикс «/» у имени — доля от остатка после предыдущих долей);
  • последний фрагмент без «=» — остаток b целиком на этот вид (резерв);
  • имена в нижнем регистре; если имя входит в UGLI1, значение пишется в EquipmentGroupExtraFuelParam, иначе — в поле с тем же именем на EquipmentGroupFuelParam (_apply_parsed_values).

На странице формул топлива задаётся тот же formtxt, что участвует в расчёте.

EquipmentGroupFuelParam — основные и углеводородные показатели (в т.ч. gaz (Газ), mazut (Мазут), don (Дон), kuzn (Кузбасс), …); подписи столбцов — как в шапке таблицы «Рассчитанные параметры» / основные топливные параметры на этой странице и на странице основных параметров.

EquipmentGroupExtraFuelParam — детальные поля «доп. углей» и прочие из набора формулы; для каждого nazvl в шапке таблицы «доп. параметры» на этой странице показывается наименование из справочника топлива (как на странице редактирования топливных параметров).

Агрегирование

После подстановки долей вызывается _aggregate_main_fuels по словарю GROUPS в коде сервиса: для каждого родителя (например pech (Печ), kuzn (Кузбасс), gaz (Газ), mazut (Мазут)) в соответствующее поле EquipmentGroupFuelParam записывается сумма дочерних полей с EquipmentGroupExtraFuelParam (например для pech — intin + vork; для gaz — gaz_prir + gazpp — подписи дочерних колонок в шапке таблицы доп. параметров).

Поле ugol (Уголь) на основной записи задаётся отдельно: это сумма всех полей из набора UGLI на EquipmentGroupFuelParam, кроме самого ugol (все агрегаты углей и родственные колонки, участвующие в разложении).

Итог совпадает с колонками групп и «угля» на той же странице основных параметров, что и после ручного ввода формулы.

Снова EquipmentGroupFuelParam: обновляются групповые поля по правилам GROUPS — pech (Печ), kan (Канск), kuzn (Кузбасс), ural (Урал), gaz (Газ), mazut (Мазут), … — и итог ugol (Уголь); подписи как в шапке основной таблицы на этой странице.

Дочерние значения берутся из EquipmentGroupExtraFuelParam (колонки доп. параметров с теми же именами полей и подписями из справочника, см. редактирование топливных параметров).

Сохранение При стандартных настройках — один коммит транзакции в конце пакета (final_commit); при commit_each — после каждой группы. Те же строки БД для выбранного year_number (год в таблицах «Рассчитанные параметры» на этой странице; колонки годов совпадают с фильтром года на страницах основных и доп. топливных параметров)

Сверка с карточкой группы и разделом «Расчёт»

  • Пакетный расчёт на этой странице обновляет строки EquipmentGroupFuelParam и EquipmentGroupExtraFuelParam для выбранного года расчёта по формуле formtxt и энергобалансу (см. таблицу выше). Он не подменяет вручную введённые на карточке группы поля удельных показателей y, btp, sntp, bk, snk, k — они задаются на странице групп оборудования / редактирование группы.
  • Расчётные поля удельных *_calc на карточке группы только для просмотра; их пересчёт выполняется сервисом после сохранения (по параметрам топлива и вводимым удельным), а не этим пакетом.
  • Цена (xxx_c) на карточке группы — производная от стоимости и количеств топлива; при сохранении карточки пересчитывается отдельным шагом, не пакетом на этой странице.
  • Предпросмотр таблиц ниже (основные / доп. параметры после расчёта) соответствует данным, которые пакет записал в БД для выбранных групп и года.
