# Страницы анализа рациональной структуры

## Навигация

1. «Отчетные данные»: четыре прежние кнопки Техинспекции.
2. «Анализ данных»: «Расчет наработки ЕГО» и «Расчет замыкающей цены».
3. Горизонтальная разделительная полоса.
4. «Расчетные значения»: две прежние кнопки исходных территориальных данных.

## Новые страницы

- `/rational_structure/equipment_runtime`: лист «Расчет», 1915 строк оборудования; фильтры энергозоны, года отчетности, поиск, пагинация. Вкладка сводки листа «Лист2»: 80 строк.
- `/rational_structure/marginal_price`: пять территорий, 2025–2042 годы, по 10 периодов на год; 900 строк суммарно.
- Для каждой страницы есть собственные роут, сервис и HTML. Общие таблица, навигация и оформление вынесены в переиспользуемые шаблоны. Использованы общие стили раздела с зеленой шапкой, крупным шрифтом и горизонтальной прокруткой, как в таблицах экологии.

## Данные и ограничения

Обе книги сохранены в новой таблице `gs_rs_calculation_workbooks` только для версии **«ГС 2023-2042 (утвержденная)», ID 46**. Сетевой диск не нужен при открытии страниц. В других версиях отображается сообщение об отсутствии загруженной книги.

Это просмотр сохраненных результатов Excel, а не автоматический пересчет по текущим данным АРМ. Формулы сохранены для справки и выводятся в подсказках. Внешние ссылки не исполняются. В листе расчета наработки 174 ячейки содержат исходные ошибки Excel: они выделяются, не подменяются нулями. Сохраненный пустой строковый результат формулы не считается ошибкой. Сводка «Лист2» – самостоятельная сохраненная сводка исходного файла, а не агрегация текущего фильтра оборудования.

Для повторной загрузки после применения миграции:

```powershell
.venv\Scripts\python.exe -X utf8 scripts/import_rational_structure_calculations.py --runtime "Путь/Расчет наработки ЕГО.xlsx" --price "Путь/Расчет замыкающей станции.xlsx" --apply --version-id 46
```

Без `--apply` скрипт только читает и проверяет книги. Для записи обязательна явно указанная версия. Книги проверяются до начала записи, обе сохраняются одной транзакцией.

Миграция `rs26102605` применена адресно. Как и до этой задачи, маркер `alembic_version` локальной БД отстает от фактической схемы; общий маркер не менялся. Перед общим `upgrade` необходимо согласовать историю с фактической схемой.

## Проверки

- 38 целевых тестов новых страниц, навигации и соседних таблиц прошли.
- Новые Python-файлы прошли компиляцию.
- Значения, формулы и отметки ошибок из БД полностью совпали с повторным разбором исходных книг; контрольные суммы сохранены в `verification.json`.
- На реальных данных приложения отрисованы стартовая страница, расчет оборудования, сводка ресурсов и все пять территориальных страниц цены.
- Интерактивная проверка в авторизованном браузере не проводилась: в доступной сессии нет сохраненных учетных данных.
