# Изменения в логике отображения станций по собственникам

## Проблема
При отображении изменений по станциям на странице `station_changes_list` возникала проблема, когда у одной станции агрегаты находились с разными генерирующими компаниями. Это ломало логику отображения rowspans в таблице.

## Решение
Реализована логика разделения станций на "виртуальные станции" по принадлежности агрегатов к разным генерирующим компаниям. Теперь каждая комбинация (станция + генерирующая компания) отображается как отдельная условная станция с одинаковым наименованием, но с разными собственниками.

## Внесенные изменения

### 1. Файл: `app/generation/services/station_changes_services/station_changes_services.py`

#### Класс `VirtualStation`
Добавлен новый класс-обертка для представления виртуальных станций:
```python
class VirtualStation:
    """Обертка для станции с привязкой к конкретной генкомпании"""
    def __init__(self, station, gen_company_id, machines):
        self._original_station = station
        self._virtual_gen_company_id = gen_company_id
        self.machines = machines
    
    def __getattr__(self, name):
        # Делегируем все атрибуты оригинальной станции
        return getattr(self._original_station, name)
```

#### Функция `get_station_changes_list_data`
Модифицирована логика обработки станций:
- Группировка агрегатов по комбинации (станция, генкомпания)
- Создание виртуальных станций для каждой уникальной комбинации
- Применение rowspans отдельно для каждой виртуальной станции

#### Функция `apply_all_rowspans`
Обновлена логика расчета rowspans:
- Rowspan для генерирующей компании теперь рассчитывается по `gen_company.id` вместо кортежа
- Rowspan для топлива группируется только по `fuel_so`
- Добавлена документация о работе с виртуальными станциями

## Результат
✅ Станции с агрегатами от разных генерирующих компаний теперь корректно отображаются как отдельные строки в таблице  
✅ Каждая виртуальная станция имеет одинаковое название, но привязана к своему собственнику  
✅ Rowspans рассчитываются корректно для каждой виртуальной станции  
✅ Сохранена совместимость с существующими шаблонами отображения  

## Пример отображения

### До изменений:
```
Субъект РФ | Генкомпания 1 | Станция А | агрегат 1
           | Генкомпания 2 |           | агрегат 2
```
(некорректные rowspans, проблемы с отображением)

### После изменений:
```
Субъект РФ | Генкомпания 1 | Станция А | агрегат 1
Субъект РФ | Генкомпания 2 | Станция А | агрегат 2
```
(каждая комбинация отображается как отдельная условная станция)

## Технические детали
- Виртуальные станции создаются только для комбинаций, где есть агрегаты
- Если станция относится к нескольким региональным энергосистемам, она корректно отображается в каждой из них
- Общее количество виртуальных станций может быть больше количества физических станций
- Атрибут `_virtual_gen_company_id` используется для внутренней идентификации виртуальных станций
