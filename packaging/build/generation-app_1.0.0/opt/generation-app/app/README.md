Проект: Энергогенерация — справочники (refdata) и генерация

## Быстрый старт

- Установите зависимости проекта и переменные окружения (`.env`).
- Запустите приложение:

```bash
python run.py
```

По умолчанию используется конфигурация из `config.py` и переменные окружения.

## Тестирование (pytest)

В репозитории добавлены модульные тесты для части refdata (роутеры и сервисы). Тесты изолированы от БД и Redis — обращения к сервисам/БД замоканы.

- Запуск всех тестов:

```bash
pytest -q
```

- Структура тестов:
- `tests/conftest.py`: минимальный Flask-приложение для тестов, фикстуры клиента и вспомогательные утилиты
- `tests/refdata/test_fuel_routes.py`: тесты роутов `fuel` (`/refdata/fuel`, добавление, экспорт)
- `tests/refdata/test_energy_area_routes.py`: тесты роутов `energy_area` (список, удаление, экспорт)
- `tests/refdata/test_fuel_services_unit.py`: юнит-тесты сервиса `fuel_services` (валидации, уникальность, not found)

Тесты роутов используют `LOGIN_DISABLED=True`, поэтому не требуют авторизации. Доступ к БД/Redis и побочным сервисам эмулируется через `unittest.mock.patch`.

## Переменные окружения (основные)

- `DB_USER`, `DB_PASS`, `DB_HOST`, `DB_PORT`, `DB_NAME` — параметры подключения к Postgres
- `SQLALCHEMY_DATABASE_URI` — альтернативный DSN (если используется напрямую)
- `REDIS_URL` — URL Redis для кэша и сессий
- `SECRET_KEY` — ключ Flask

См. подробности в `config.py`.

## Полезные директории

- `app/refdata` — модели, сервисы и маршруты справочников
- `app/generation` — логика генерации и связанные сущности
- `app/templates` — шаблоны Jinja2
- `README/VERSIONING` — документация по версионности данных

## Примечания

- Для интеграционных тестов с реальной БД потребуется развернуть Postgres и инициализировать схемы (см. миграции в `migrations/`).
- Добавленные тесты демонстрируют подход: покрытие роутов через мок сервисов и покрытие сервисов через мок `db.session`/`Model.query`.
