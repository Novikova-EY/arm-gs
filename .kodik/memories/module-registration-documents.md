---
title: "Отдельный документ для каждого модуля"
---

При подготовке описаний модулей АРМ ГС для государственной регистрации пользователь требует отдельный файл для каждого модуля. Не объединять описания разных модулей в один Word-документ. Оформление брать из согласованного отчета; для каждого документа делать собственные титульный лист, оглавление и нумерацию.
